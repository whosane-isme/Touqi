# Touqi benchmarks

How Touqi measures performance, and the results so far.

- [methodology.md](methodology.md): what is measured, how runs are compared, known noise.
- [tas-replay.md](tas-replay.md): recording and replaying a route with the controller.
- [hardware-profiles.md](hardware-profiles.md): the machines results come from.
- [results/](results/): one file per measurement session.

The tooling itself lives in [tools/oot-bench](../../tools/oot-bench/README.md); run everything
with `make` from that folder.
